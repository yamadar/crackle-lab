# Crackle Lab

貫入(クラック)パターン図鑑。手続き的アルゴリズムをパラメータ調整しながら試せる SPA。

## セットアップ

```bash
npm install
```

## 開発

```bash
npm run dev
```

`http://localhost:5182/` が自動で開きます。

## テスト・ビルド

```bash
npm test
npm run build
```

## アーキテクチャ

モジュール構成・設計の詳細は [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md) を参照。
